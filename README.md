# Cogollera Web - Dashboard IoT en Vercel + Supabase

Frontend web para visualizar la telemetría del ESP32 en tiempo real (Temperatura interna y Contador cada 10 segundos).

---

## 1. Configuración de Supabase (Base de datos en la nube)

1. En tu proyecto de [Supabase](https://supabase.com), ve al **SQL Editor** y ejecuta este comando para crear la tabla de datos y habilitar WebSockets en tiempo real:

```sql
-- 1. Crear tabla de mediciones
create table mediciones (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  temperatura float not null,
  contador int not null
);

-- 2. Habilitar Supabase Realtime (para que la web reciba datos en vivo)
alter publication supabase_realtime add table mediciones;

-- 3. Habilitar permisos de lectura y escritura para el ESP32 y la Web
alter table mediciones enable row level security;
create policy "Permitir lectura publica" on mediciones for select using (true);
create policy "Permitir insercion publica" on mediciones for insert with check (true);
```

2. Ve a **Project Settings ➡️ API** y copia:
   - **Project URL** (ej: `https://xyz.supabase.co`)
   - **anon / public key**

---

## 2. Cómo conectarlo en la web

1. Abre `index.html` (o tu link de Vercel).
2. Abajo en el panel de configuración, pega tu **URL** y **Anon Key**.
3. Haz clic en **Conectar**. Quedarán guardadas en tu navegador y recibirás las actualizaciones en vivo cada vez que el ESP32 inserte un registro.

---

## 3. Despliegue en Vercel

1. Sube este repositorio a tu GitHub: `https://github.com/Lorenzo-Imvinkelried/cogollera-web`.
2. En [Vercel](https://vercel.com), dale a **Add New... ➡️ Project**, selecciona `cogollera-web` y haz clic en **Deploy**.
3. ¡Listo! Tendrás tu dashboard en una URL pública `https://cogollera-web.vercel.app` para ver tus datos desde cualquier lugar.
